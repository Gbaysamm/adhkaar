# Recording the recitations

Every dhikr can have a recitation. The app looks for a file named after the dhikr's id in
`app/src/main/assets/audio/`. If the file is there, a play button appears; if not, nothing changes.

## How to record

- **Recite each dhikr once per file.** Don't repeat it for the count: the app repeats nothing, and the counter is the reader's.
- Use a quiet, soft room (a wardrobe full of clothes works well) and keep the phone or mic about a hand's width away.
- Leave about half a second of silence at the start and end, and keep the same distance and volume for every file.
- Export as **.m4a (AAC), mono, 64–96 kbps**. mp3, ogg, opus and wav also work.
- Name each file exactly as in the list below, e.g. `ayat_al_kursi.m4a`.
- Have a teacher check the tajweed before release.
- Five adhkaar are worded differently in the evening (*amsaynā* instead of *aṣbaḥnā*). Record the evening wording as `<id>_evening`. In the evening session the app plays only that file, never the morning one, so the words always match.
